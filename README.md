# Daily Coding Challenge

One interview problem a day, with a gentle start on Monday and the toughest puzzles on Sunday.

**[Play today's challenge](https://jackeown.github.io/daily-coding-challenge/)**

Write a function in Python, C++, C, Java, JavaScript, or Rust. Run the example, then check all tests. Some problems include a large timed case. Your drafts, solved days, and theme stay in your browser.

The 42 puzzles are my own adaptations of familiar interview problems. Where a puzzle draws on LeetCode, its page links to the original. The six-week set repeats.

The site is plain HTML, CSS, and JavaScript on GitHub Pages. Code runs in [OneCompiler's embedded editor](https://onecompiler.com/apis/embed-editor), so it needs an internet connection. The tests are for practice, and runner speed can vary.

To work on it locally, run `python3 -m http.server 8000` in this folder and open `http://localhost:8000`.
